# 📊 Finsler-Based Topological Analysis of Neuronal Data

This project explores the relationship between neuronal connectivity and **orientation selectivity** using tools from **Topological Data Analysis (TDA)** and **Finsler geometry**.

We analyze neural responses under different visual stimuli (e.g., drifting, static, noisy gratings) and construct simplicial complexes from correlation structures to compute topological invariants such as **Betti numbers** and **Euler characteristic**.

---

## 🧠 Motivation

Understanding how neurons organize and interact depending on their orientation selectivity is a fundamental problem in neuroscience. This project introduces a **geometry-driven approach**, where:

- Correlations between neurons are interpreted through a **Finsler-inspired metric**
- Resulting structures are analyzed using **persistent homology**
- Topological features reveal patterns in neural organization across stimuli
